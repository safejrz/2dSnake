# 2D Snake

A small, retro-style Snake game that runs in your browser. Eat the food to grow your score and speed up, but avoid the walls and your own tail.

**[Play the live preview](https://safejrz.github.io/2dSnake/)**

## How to play

- **Keyboard:** Use the arrow keys to steer. Press **Space** to restart.
- **Touchscreen:** Swipe across the game area to steer. Tap the game area after a game over to retry.

## Run locally

There are no dependencies or build steps. Open `index.html` in a modern browser, or serve the project directory with any static web server.

## Project files

- `index.html` — game markup, styles, and JavaScript.
- `Meme.gif` — background image used by the game page.
